# Mattu Di Hatti — Premium Static Frontend

This version is a static HTML/CSS/JavaScript recreation of the visual direction of the supplied premium Mattu Di Hatti reference:
- dark luxury festive theme
- navy / royal blue / gold palette
- editorial Playfair Display headings + DM Sans body
- cinematic fireworks hero
- announcement strip + sticky navigation
- large image-led category cards
- split brand story section
- wholesale / retail CTA
- Instagram section
- store/location section
- responsive mobile bottom bar

No React, backend, database, authentication, checkout or real form submission.

## Run
Open `index.html` directly or use VS Code Live Server.

## Assets
The supplied reference package's `mattu-logo.png` and `business-banner.png` are included locally.
